# Antiyoy Barracks

Клон механик [Antiyoy](https://antiyoy.fandom.com/wiki/Antiyoy_Wiki) с **домиками призыва** юнитов.

## Запуск в браузере

```bash
npm install
npm run dev
```

Сборка веба: `npm run build` · Тесты: `npm test`

## Десктоп-приложение (скачать / собрать)

Игра упакована через **Electron**. Готовые установщики появляются в папке `release/`.

```bash
npm install

# Собрать установщик под текущую ОС
npm run desktop:dist

# Или точечно:
npm run desktop:dist:linux   # AppImage
npm run desktop:dist:win     # ZIP с .exe внутри
npm run desktop:dist:mac     # .dmg
```

Быстрый локальный запуск без установщика:

```bash
npm run desktop        # сборка + окно Electron
npm run desktop:dev    # hot-reload через Vite
```

**Windows:** распакуйте `Antiyoy Barracks-*-windows.zip` и запустите `Antiyoy Barracks.exe`.  
**Linux:** скачайте `.AppImage`, затем `chmod +x *.AppImage` и запустите.  
**macOS:** откройте `.dmg` (собирается на Mac).

## Меню партии

Перед стартом можно выбрать:
- число игроков (2–8) и сколько из них люди (остальные — ИИ)
- размер карты
- **сложность ИИ** (лёгкий / обычный / сложный / эксперт)
- цвет и название государства каждого игрока

Колёсико мыши — масштаб карты (также `+` / `-`).

## Юниты

| Ранг | Фигурки |
|------|---------|
| 1 | 5 ополченцев |
| 2 | 10 солдат |
| 3 | 3 спецназовца + пулемётная машина |

Также отрисованы фигурки столицы, ферм, башен и домиков I–IV.

- Гексагональная карта, провинции, монеты, фермы, башни, деревья
- Юниты рангов 1–4, защита соседних клеток, захват при `ранг > защита`
- Содержание юнитов, голод при отрицательном балансе
- ИИ-соперники, отмена хода, хотсит по кругу

## Домики (новый функционал)

| Домик | Стоимость | Вызов юнита | Время появления |
|------|-----------|-------------|-----------------|
| I    | 25🪙      | ранг 1, 10🪙 | 1 ход           |
| II   | 50🪙      | ранг 2, 20🪙 | 2 хода          |
| III  | 90🪙      | ранг 3, 30🪙 | 3 хода          |
| IV   | 150🪙     | ранг 4, 40🪙 | 4 хода          |

1. Постройте домик нужного ранга в провинции.
2. Выберите домик → **Вызвать юнита**.
3. Через N ваших ходов юнит появляется на соседней свободной клетке.

Юнитов нельзя купить «с воздуха» — только через домики.
