# Antiyoy Barracks

Браузерный клон механик [Antiyoy](https://antiyoy.fandom.com/wiki/Antiyoy_Wiki) с дополнительными **домиками призыва** юнитов.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` · Тесты: `npm test`

## Классика Antiyoy

- Гексагональная карта, провинции, монеты, фермы, башни, деревья
- Юниты рангов 1–4, защита соседних клеток, объединение, захват при `ранг > защита`
- Содержание юнитов, голод при отрицательном балансе
- ИИ-соперники, отмена хода, хотсит по кругу

## Домики (новый функционал)

| Домик | Стоимость | Вызов юнита | Время появления |
|------|-----------|-------------|-----------------|
| I    | 25🪙      | ранг 1, 10🪙 | 1 ход           |
| II   | 50🪙      | ранг 2, 20🪙 | 2 хода          |
| III  | 90🪙      | ранг 3, 30🪙 | 3 хода          |
| IV   | 150🪙     | ранг 4, 40🪙 | 4 хода          |

1. Постройте домик нужного ранга в провинции.
2. Выберите домик → **Вызвать юнита**.
3. Через N ваших ходов юнит появляется на соседней свободной клетке.

Юнитов нельзя купить «с воздуха» — только через домики.
